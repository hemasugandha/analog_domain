# analog_domain
This repo contains the projects related to the CMOS Image sensor, CMOS OTA, BGR circuit

## 1. CMOS OTA in Cadence Virtuoso
Designed and simulated a two-stage CMOS 5-transistor OTA in GPDK90nm technology using Cadence Virtuoso and verified 
the DC,AC and PVT analysis.

## 2. CMOS Image Sensor in Cadence Virtuoso
Designed and simulated 3T and 4T CMOS Active Pixel Sensor(APS) architectures, incorporating Correlated Double Sampling(CDS)
for noise reduction. Implemented a current-steering DAC-based counter for pixel readout and image acquisition.

## 3. BGR circuit in Cadence Virtuoso
Designed and simulated a CMOS Bandgap Reference (BGR) using PTAT and CTAT compensation techniques to generate a temperature-stable reference voltage.
Implemented OTA based regulation, biasing, and current mirror circuits, and verified performance through DC, AC, and Temperature analysis.
